The calibration FAIL from Round 1 cannot be closed with a numeric accuracy threshold that is established by the search results. No validated, pre-registered calibration accuracy gate for this specific probe-and-run architecture appears in the available evidence. What the literature does establish is that ECE gates around 0.05 are common illustrative defaults, not validated thresholds, and that sample sizes below roughly 100–150 produce unstable ECE estimates. Proposing a specific number for this system would require inventing a threshold, which the task forbids.

Proposed threshold structure (unlocked number, locked metric). The defensible position is to lock the metric while leaving the number unlocked pending a calibration run. The metric should be stated-confidence-only Expected Calibration Error (ECE) with reliability-diagram monotonicity, because ECE directly measures the confidence–accuracy alignment that the underconfident-agent FAIL implicates. An accuracy threshold alone would not distinguish underconfidence from simple inaccuracy: a model can be 70% accurate and badly underconfident (stating 40% when correct 70% of the time), or 70% accurate and well-calibrated. The gate must therefore be on calibration error, not accuracy. Illustrative defaults in the literature place ECE at ≤ 0.05 with accuracy ≥ 0.90, explicitly flagged as “illustrative defaults, not validated or pre-registered thresholds”. Another source sets the minimum at ECE ≤ 0.05 across ≥ 100 resolved cases with monotonic accuracy by confidence bucket, also without claiming validation. These are starting points for negotiation, not established numbers this build can lock unilaterally.

Sample size and tolerance. ECE estimates at n = 50 have standard deviation ≈ 0.038; at n = 100, ≈ 0.026; at n = 250, ≈ 0.015. A 14-pair probe is far below the threshold at which ECE is stable: 14 pairs cannot support a calibration accuracy gate with any meaningful confidence interval. The 80-pair run is also below the n = 100 stability floor. If a threshold is to be measured, it must be measured on a sample of at least 100–150 scored pairs, with a reported bootstrap confidence interval and an explicit rule that a CI straddling the threshold yields an inconclusive gate rather than a pass. The 14-pair probe should not be gated on calibration accuracy at all; it should gate only coverage and validity screening (confidence availability, non-degeneracy). The 80-pair run may carry a provisional calibration gate, but only with a clearly stated tolerance (e.g., ECE point estimate ≤ threshold and upper CI bound ≤ threshold + 0.02), and only if the 80 pairs are scored against resolved outcomes.

Mechanism question: threshold artefact vs structural decoupling. This is the central distinction the Round 4 question demands. A threshold artefact occurs when the measured underconfidence is an artifact of binning, sample size, or the probe's difficulty distribution. It would manifest as: underconfidence concentrated in a few bins with small counts; ECE improving materially when the sample is enlarged or bins are re-specified; and confidence not tracking accuracy monotonically across the full range. A structural decoupling of confidence and evidence occurs when confidence is systematically compressed or insensitive to correctness regardless of binning. It would manifest as: underconfidence across all bins in the reliability diagram; near-zero discrimination (AUROC close to 0.5 for confidence predicting correctness); and the pattern persisting identically on 100% of scored pairs or ≥ 90% with zero discordant confidence–accuracy dissociations. The threshold itself cannot distinguish these; the diagnostic pattern around the threshold can. Therefore, if the underconfident pattern holds on 100% of scored pairs, or ≥ 90% with zero discordant cases, re-scoring should stop and the defect should be routed as a mechanism fault regardless of whether the ECE number passes. A passing ECE with a structural decoupling pattern is a false pass: the model is uniformly underconfident in a way that a single aggregate number can mask.

Gating decision. The threshold should gate the 80-pair run only, provisionally. The 14-pair probe is too small for calibration measurement; it gates coverage and validity, not calibration accuracy. If the provisional threshold is unmet at the 80-pair stage, the probe does not “fail calibration” in a way that closes the Round 1 FAIL; it fails to close the FAIL, and the system proceeds to a larger calibration sample before any routing or escalation decision is made on confidence. The consequence of leaving the number unlocked is that the calibration FAIL remains open, no confidence-keyed routing is permitted, and the system must either commit to a pre-registered number before the 80-pair run or accept that the run is diagnostic only and not gating. Leaving it unlocked is not neutral: it means the underconfident-agent FAIL from Round 1 persists as an unresolved risk, and any downstream use of confidence scores remains unsupported.
