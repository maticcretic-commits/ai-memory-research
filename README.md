# AI Memory Research — private archive

Research programme (October 2026) into memory systems that drive decisions,
not just context: how memory should work, how it can talk back, and what
evidence would justify trusting it.

## How to navigate

- `BRIEF.md` — the vast-scope brief: 8 research areas.
- `PROGRESS.md` — period-by-period log of everything that happened.
- `rounds/` — one directory per partner round (brief, verbatim inbox replies,
  synthesis). Rounds 1–8 are complete.
- `creator-studies/` — catalogues and studies of three creators' skills
  (Jeff Su, Nate Herk, Sirio Berati), including the transcript-panel record.
- `CREATOR-SKILLS-IMPLEMENTATION.md` — skill-by-skill mapping to system
  modules, with governance classes.
- `prototypes/phase1/` — safe prototypes: synthetic inputs only, drafts only,
  standard library only. 68 tests green.
- `phase2-draft-records/` — draft records in audit format. They certify nothing.
- `STUDY-VISUALISERS-2026-10-27.md`, `STUDY-OMNIDIM-TALKBACK-2026-10-27.md`,
  `BRIEF-VISUAL-TALKBACK-DRAFT-2026-10-27.md` — talk-back studies and the
  held visual talk-back draft.
- `source/` — the source export received 26 October 2026 (code, corpus,
  live-memory records), as received.
